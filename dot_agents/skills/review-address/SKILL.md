# レビューコメント対応

1. 指定されたPR、または現在のbranchに対応するPRを特定する。
2. inline review commentsとPR全体のコメントを`gh`で取得する。
3. inline replyは親コメントを基準にthread単位でまとめる。
4. 通知のみのbotは除外し、レビュー、品質、セキュリティ系botは評価対象にする。
5. 指摘箇所を読み、各コメントの技術的妥当性を判断する。
6. 妥当な指摘は、無関係な範囲へ広げずに修正する。
7. 製品仕様や設計判断が曖昧な場合だけユーザーへ確認する。
8. 適切な検証を実行し、最終差分を確認する。
9. 論理的な単位で`commit`の手順を実行する。
10. このskillは明示依頼が必要なため、修正commitをpushしてよい。
11. 対応したコメントへ簡潔に返信し、関連するcommit hashを含める。
12. 対応しない指摘には、具体的な技術的理由を示す。
13. PRをmergeしない。
14. 対応済み、非対応、保留、未解決のコメントを報告する。
